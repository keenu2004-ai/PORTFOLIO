# Vaibhav Rajput — Personal Engineering Portfolio

> **Sales Engineer | Full-Stack Product Engineer**

A production-focused personal engineering portfolio built to showcase full-stack product development, software architecture, security, DevOps, and selected embedded/IoT work.

**Live portfolio:** https://portfolio.vaibhavcloud.cloud/

---

## Overview

This portfolio is a React-based application designed around a clear engineering story: from product requirements and user experience through application architecture, backend systems, deployment, and production delivery.

The site includes interactive project showcases, technical skill sections, engineering experience, services, certifications, GitHub integration, contact functionality, and a dedicated breakdown of containerized delivery.

## Engineering Highlights

- React 19 + TypeScript application architecture
- Vite-based production build and optimized asset delivery
- Custom CSS design system using Flexbox, Grid, gradients, and responsive layouts
- Interactive SVG visualizations and UI animations
- Three.js / React Three Fiber integrations for interactive 3D experiences
- SEO and social metadata including Open Graph and Twitter cards
- `sitemap.xml`, `robots.txt`, and `llms.txt`
- Accessibility-focused markup and responsive behavior
- Production bundles generated without source maps
- Docker/Nginx deployment configuration

## Application Structure

The portfolio is organized into focused sections/components:

- **Hero** — primary positioning and navigation
- **About** — engineering background and technical highlights
- **Skills** — categorized technology stack
- **Flagship Project** — interactive THEIAKSHI HRMS system showcase
- **Projects** — selected engineering work with repository links
- **Experience** — professional and education timeline
- **DevOps** — end-to-end containerized delivery breakdown
- **Services** — technical capabilities
- **Certifications** — qualifications and credentials
- **GitHub** — profile and repository presentation
- **Contact** — direct inquiry interface
- **Not Found** — custom 404 experience

## Local Development

### Prerequisites

- Node.js 18+
- npm

### Install

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Production Output

The production build generates a `dist/` directory containing optimized frontend assets and metadata for search engines and social sharing.

The deployment setup also uses Docker/Nginx for serving the production application.
