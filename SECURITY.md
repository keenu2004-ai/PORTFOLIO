# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues.

For security-related concerns, contact me privately through the contact details listed on my portfolio:

https://portfolio.vaibhavcloud.cloud/

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce the issue
- The potential impact
- Any relevant logs, screenshots, or proof of concept

I will review legitimate reports and work to address verified vulnerabilities responsibly.

## Scope

This policy applies to the software and services contained in this repository.

Please avoid testing against production systems in ways that could disrupt availability, access other users' data, or cause data loss.
